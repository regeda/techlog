How it works

Capture. Connect. Use.

Techlog connects engineering context across agents, sessions, and the tools you already use. It is not another place to store artifacts, and it does not replace GitHub, Jira, Slack, your docs, code review, or engineering judgment.

  1. 1📝

    Agents capture context

    AI agents record engineering problems, decisions, code changes, releases, and incidents as work evolves.

    Capture the why, not just the code.

  2. 2🔗

    Techlog connects events

    Related events are linked across tools. Provenance and evidence are kept, and a confirmed link is told apart from a hypothesis.

    One connected engineering history.

  3. 3🔎

    Agents find answers

    AI agents query past decisions, investigate incidents, find similar failures, and reuse earlier investigations.

    Turn engineering history into useful context.

  • Proposed · draft 0.1

    Open event standard

    What an event looks like, so any tool can write and read it.

  • Implemented · basic

    MCP interface

    How agents record and query events, such as techlog_record_event.

  • Local only

    Techlog platform

    Stores and links events. A basic server runs locally; there is no hosted service or tool connector yet.
