MCP and Techlog

The Model Context Protocol (MCP) is how an agent talks to a tool. Techlog defines what the events mean and how the lifecycle fits together. An agent that already speaks MCP needs no custom client code to read history or record progress.

Tools

ToolPurpose
techlog.search_eventsSearch events by text, type, system, and time range.
techlog.get_system_historyRead the chronological history of one system, optionally with links.
techlog.record_eventRecord a structured event. The recorder assigns the id.
techlog.link_eventsLink two events. Causal links must state confirmed or hypothesis.
techlog.create_rollback_planPrepare a draft rollback plan for an upgrade. A draft needs review before it counts as evidence.
techlog.submit_evidenceAttach an evidence reference, optionally with a digest, to an event.

Resources

Proposed URIs a client could read directly:

  • techlog://systems/{system}/history
  • techlog://events/{id}
  • techlog://plans/{id}

Prompts

  • investigate_incident(incident_id): gathers the incident, its release, and the linked changes, and asks for a hypothesis.
  • prepare_rollback_plan(system, target_version): drafts a plan from the system's history for a person to review.
  • record_decision(event_id): asks for the decision, its approver, and the terms, and records them against a proposal.

Agent walkthrough

  1. Retrieve history. techlog.get_system_history for promo-api, to see what shipped recently.
  2. Inspect the incident. techlog.search_events for incident.opened returns evt_01J9K2A0P011, linked to the 3.8.0 canary.
  3. Record an event. techlog.record_event with an investigation.completed event that links back to the incident.
  4. Create a rollback plan. techlog.create_rollback_plan for the next upgrade. The plan starts as a draft.
  5. Submit evidence. techlog.submit_evidence attaches the test report to the change.

Agent safety

An event submitted by an agent carries actor.kind: ai_agent and provenance.method: agent_submitted, so a reader can always tell it apart from a collected or human-entered event. An agent never grants an approval for its own submission. See security and trust.
